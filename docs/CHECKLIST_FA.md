**گیت کیفیت:** `npm run quality:ux` افزودن الگوهای قطعیِ ممنوع در UI، فایل آزمون ناموفق خارج از خط مبنا و پیام TypeScript تازه را رد می‌کند. اجرای محلی ۱۳۶ PASS و همان ۱۳ FAIL پیشین با ۵۰۶ پیام TypeScript و صفر پیام تازه ثبت شد. سه قرارداد Primitive پس از انتقال منطق به Hook و CSS مشترک همان رفتار را در محل جدید بررسی می‌کنند. گردش GitHub Actions شامل Build و Playwright است و وضعیت اجرای GitHub جدا از نتیجهٔ محلی بررسی می‌شود.

## ثبت اجرای F4-04 / F2-14 — کنترل نسخه و دامنهٔ وظیفه در API

- پنل گردش کار نسخهٔ رکورد را از DataProvider می‌گیرد. API هنگام ثبت، رکورد را در تراکنش قفل می‌کند، نسخه و انتقال را اعتبارسنجی می‌کند و نتیجه و ممیزی با شناسهٔ کاربر احرازشده با هم ثبت می‌شوند. درخواست قدیمی با `409` و امکان دریافت نسخهٔ تازه پاسخ داده می‌شود. ذخیرهٔ عمومی، بازنویسی گردش ثبت‌شده با نسخهٔ قدیمی یا دست‌کاری فیلدهای گردش را رد می‌کند.
