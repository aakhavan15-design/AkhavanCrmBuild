# AKHAVAN CRM

سامانه جامع فارسی/راست‌چین و موبایل‌اول مدیریت، اتوماسیون، پایش، کنترل و هوشمندی کسب‌وکار؛ یکپارچه با ERP و شامل داشبورد مدیریتی، تسک و گردش کار، مشتری و فروش، سفارش و فاکتور ERP، مذاکره و افزایش فروش، مطالبات و وصول، مالی و توان پرداخت شرکت، سودآوری، انبار، منابع انسانی و رشد کارکنان، هوش جغرافیایی، پایش مغایرت و گزارش‌های تحلیلی. ERP مرجع تراکنش‌های رسمی است؛ CRM داده را تحلیل و به اقدام قابل پیگیری تبدیل می‌کند.

برای شروع کار (انسان یا هوش مصنوعی) فقط `INSTRUCTIONS.md` را بخوانید؛ همهٔ مستندات از آنجا لینک شده‌اند. اجرای آزمون‌ها: `node scripts/run-tests.mjs`.
